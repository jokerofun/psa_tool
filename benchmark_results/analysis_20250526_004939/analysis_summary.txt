--- Overall Findings ---
On average, DuckDB is 1.86x slower than In-Memory for execution time.
The performance gap decreases with larger data sizes (change of -1.07x).
On average, DuckDB uses 3.15x more memory than In-Memory.
The memory usage difference decreases with larger data sizes (change of -5.79x).

--- Recommendations ---
In-Memory performs better in both time and memory. Only use DuckDB when persistence is required.
